# 氢CMS · 服务器监控大屏

> 沧州虎王科技 为 **氢CMS（Carbon CMS）** 开发的一体化 **服务器监控大屏**
> 通过 PHP 环境实时采集并上报服务器状态，支持统一管理、集中展示、告警与审计。
> 项目开源，含多个主题版本可直接下载使用。

---

## 📌 项目简介

氢CMS 服务器监控大屏是一个**零依赖、可自部署**的企业级服务器监控解决方案。它通过 PHP 脚本在服务器本地采集 **CPU / 内存 / Swap / 磁盘 / 系统负载 / 网络流量 / 运行时间** 等实时信息，以科技风大屏展示，并可将数据以标准 JSON 接口**上报**给后期统一管理系统。

- **监控端**：直接访问即可获得一个完整的监控大屏（深色科技风）。
- **上报端**：`api.php` 提供统一上报接口，供管理中心远程拉取所有被管节点数据，为规模化统一管理做准备。

---

## ✨ 核心特性

- **实时监控**：CPU、内存、Swap、磁盘、系统负载、网络流量的实时刷新大屏展示
- **服务器信息**：主机名、操作系统、架构、运行时间、PHP 环境等概要信息
- **磁盘空间**：多分区使用率、剩余容量明细展示
- **性能测试**：内置轻量 CPU / 磁盘 I/O / 网络 / PHP 性能测试
- **统一上报 API**：`api.php` 提供完整数据与心跳探测接口，供管理中心远程读取
- **可选鉴权**：节点可配置共享密钥（`?key=` 或 `X-API-Key`），防止未授权访问
- **双平台支持**：Windows（WMIC/PowerShell）与 Linux / macOS（shell 命令）
- **版本兼容**：PHP 7.4 ~ 8.5 全兼容
- **零 CDN 依赖**：CSS、JS、图标字体库全部本地化，可离线运行，适合内网部署
- **分离式架构**：数据采集、样式、脚本、接口分层解耦，便于维护与二次开发

## 🎨 多主题版本

本项目开源并包含一套可切换的显示主题版本，风格覆盖多种数据大屏场景（如科技蓝、农业生态、政务蓝、运营监控等）。不同主题版本重点在于 **`assets/css/style.css` 与页面顶部标题区** 的差异化，核心数据逻辑完全一致，可在各主题间自由切换。

| 主题 | 风格定位 | 适用场景 |
|------|----------|----------|
| `enterprise`（默认） | 深蓝企业科技风 | 通用 IT 运维监控 |
| `agriculture` | 蓝绿数据大屏风 | 生态、农业场景联调 |
| `...`（更多版本） | 随开源持续补充 | 可自行改造拓展 |

> 每个主题版本均可独立下载部署。切换主题时，仅需替换样式文件 / 调整顶部标题即可，不会影响数据采集与上报功能。

## 🚀 环境要求与部署

### 环境要求

| 依赖 | 要求 |
|------|------|
| PHP | 7.4 ~ 8.5（推荐 8.x） |
| 操作系统 | Windows / Linux / macOS |
| 可选 | `shell_exec` 已启用（采集真实系统数据；不可用时自动降级，IP 等字段显示 N/A） |

> 无需 Composer、无需数据库、无需扩展，纯 PHP 即可运行。

### 部署步骤

1. 将整个项目上传到服务器的 Web 可访问目录（如 `htdocs`、`wwwroot` 或任意虚拟主机站点根目录）。
2. 保证目录结构完整：`index.php`、`modules/`、`assets/`、`api.php`。
3. 本地 / 内网直接访问：

   ```
   http://<你的域名或IP>/index.php
   ```

4. 权限提示：若 `shell_exec` 被禁用或命令执行失败，大屏仍可正常展示，资源类字段会显示 `N/A`，不影响页面。

## 🔌 统一上报接口（api.php）

供**后期统一管理系统（管理中心）**远程读取本节点监控数据：

| 接口 | 方法 | 说明 |
|------|------|------|
| 完整上报 | `GET api.php` | 返回该节点全部监控数据（server / php / disks） |
| 心跳探测 | `GET api.php?ping=1` | 轻量在线状态检测，适合高频轮询 |
| 鉴权 | `?key=` 或 Header `X-API-Key` | 可选，需节点开启共享密钥 |

**返回示例（部分）：**

```json
{
  "success": true,
  "api": "hcms/1.0",
  "id": "node-heicat-001",
  "node_name": "氢CMS-主服务器",
  "platform": "Windows",
  "timestamp": 1792512719,
  "uptime_seconds": 13980,
  "server": {
    "cpu_cores": "16",
    "load_avg": "44, 44, 44",
    "mem_total": "15547 MB",
    "mem_used": "13853 MB",
    "net_rx": 1526.62,
    "net_tx": 280.73
  }
}
```

> 完整字段说明、三种语言对接示例（PHP / Node.js / Python）、数据模型与告警建议，详见 [`docs/api.md`](docs/api.md)。

### 节点身份配置

每个节点在 `api.php` 顶部配置唯一身份与密钥：

```php
const HCMS_NODE_ID   = 'node-heicat-001';   // 节点唯一标识
const HCMS_NODE_NAME = '氢CMS-主服务器';      // 节点显示名称
const HCMS_API_KEY   = '';                  // 为空则不校验；不为空则 ?key= 必须匹配
```

## 🧩 技术架构

```
┌────────────────────────────────────────────────────────┐
│                    管理中心（统一管理系统）               │
│                  远程读取 /api.php 数据                  │
└─────────────────────────────┬──────────────────────────┘
                              │ HTTPS / JSON
┌─────────────────────────────▼──────────────────────────┐
│                       server-monitor                    │
│  ┌──────────────┐   ┌───────────────────────────────┐   │
│  │ modules/     │   │ index.php                     │   │
│  │ collect.php  │──▶│  注入 SRV_CONFIG → 渲染大屏     │   │
│  │ (采集层)     │   └──────────────┬────────────────┘   │
│  └──────┬───────┘                  │                   │
│         │                          ▼                   │
│  Windows/Linux shell ┌────────────────────────────┐    │
│  WMIC · free · df    │ assets/css · js · fontawesome│   │
│  /proc · /proc/net   │ 本地资源（无 CDN）            │    │
│                      └────────────────────────────┘    │
└────────────────────────────────────────────────────────┘
```

- **采集层** `modules/collect.php`：统一封装平台探测与命令执行，双平台命令回退。
- **视图层** `index.php`：薄控制器，采集 → 注入 `window.SRV_CONFIG` → 输出 HTML 骨架。
- **前端** `assets/js/app.js`：读取 `SRV_CONFIG`，实时刷新、渲染节点/指标/性能测试。
- **接口层** `api.php`：复用采集层，输出标准化 JSON 供管理中心。
